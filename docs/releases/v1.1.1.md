## 修复内容

- 修复历史 Issue 主体数据缺少 `participateUsers` 时前台概览页渲染失败的问题。
- 修复历史主体缺少 Issue 模板集合时页面加载失败的问题。
- 修复历史 Issue 缺少标签集合时 Issue 列表渲染失败的问题。
- 修复历史主体、标签和模板缺少枚举字段时索引初始化可能失败的问题。
- 修复历史数据中的空主体说明、标签和模板字段导致的前台异常。

## 升级建议

升级后请重载插件，并重新访问之前无法打开的主体页面。如果页面仍使用旧模板缓存，请重载当前主题并清理主题模板缓存。

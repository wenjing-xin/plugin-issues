# 言答Issue v1.0.0

状态：待发布。说明整理于 2026-10-25，实际发布日期以 GitHub Release 为准。

本次计划从 `1.0.0-rc4` 升级至 `1.0.0`，面向 Halo 2.26.0 及以上版本。

记录基线为 2026-04-14 的 `69c5d84`（rc4）。整理时 master 最新提交仍为该提交，以下为当前 master 工作区待提交的变更汇总，并非已发布提交历史。

## 主要更新

- 完成 Halo 2.26 页面布局契约适配，主题可以通过 `templates/layout.html` 注入自己的页头、页脚和页面布局。
- 将 `packages/issue-static` 接入 Gradle 构建，启动、重载和打包时自动构建并打入插件 JAR。
- 修复前台静态资源打包和访问路径问题，产物统一进入 `static/webAssets`。
- 重做前台页面布局，采用 GitHub / Primer 风格的 Issue 列表、Issue 详情和主体概览页面。
- 优化主体概览，加入 README、About、Issue 状态统计和参与者区域。
- 优化 Issue 状态筛选，将筛选条件放入搜索框并支持删除；搜索框支持 GitHub 风格的 focus ring。
- 修复编辑器标题菜单被工具栏滚动容器裁剪的问题。
- 支持主体描述 Markdown 和安全 HTML 渲染，并过滤脚本、危险链接和 Alpine 指令。
- 支持 Issue 模板级联字段、条件显示、文章选择器和服务端条件校验。
- 修复 Issue 模板首次打开或切换主体时无法加载的问题。
- 修复经办人远程搜索关键字未正确传递的问题。
- 修复主体标签统计和标签作用范围优先级问题。
- 支持管理员、超级管理员处理其他用户创建的 Issue，包括关闭、重新打开和切换状态。
- 支持在 Issue 详情页直接分配主体可用标签。
- 完善前台发布权限、模板字段校验和失败提示。
- 使用 Halo `generateApiClient` 重新生成 API 客户端和 TypeScript 类型。
- 增加后端权限、模板条件、标签统计和前端描述渲染测试。
- 增加主题适配、构建流程、设计规范和使用文档。

## 构建与兼容性

- Halo：`>=2.26.0`
- Java：21
- Node.js：22.12.0
- pnpm：10.12.4
- 发布制品：`build/libs/plugin-issues-1.0.0.jar`

## 升级说明

升级插件后建议：

1. 在 Halo Console 重载插件。
2. 如果主题新增或修改了 `templates/layout.html`，同时重载主题并清理主题模板缓存。
3. 检查插件设置中的内容样式、分页大小和头像配置。
4. 使用管理员和普通用户分别验证 Issue 发布、审核、状态操作和评论权限。
